# wifi-radio
由于 ESP8266 自身无法直接解码 MP3 音频流，完整的网络电台方案必须外接 VS1053 或 VS1003 音频解码模块。以下方案基于 ESP8266 + VS1053 + 单色 OLED 屏幕，实现你要求的三页面显示与按键控制。代码采用框架式写法，标注了需要你自行填写的 Wi-Fi、电台流地址及天气 API 坐标。

硬件元件与针脚接法建议
核心元件清单

ESP8266 开发板（NodeMCU 或 Wemos D1 mini）

VS1053 MP3 解码模块（负责音频解码与输出）

0.96 寸 SSD1306 OLED（I2C 接口，128x64）

18650 电池 + TP4056 充电保护模块 + 3.3V 降压稳压模块（或升降压模块）

轻触按键 4 个（上一台、下一台、音量+、音量-）

电阻、电容若干（用于 VS1053 电源滤波及按键上拉）

针脚分配表

功能模块	信号线	ESP8266 引脚	备注
OLED 屏幕	SDA	GPIO4 (D2)	I2C 数据
          SCL	GPIO5 (D1)	I2C 时钟
          VCC/GND	3.3V / GND	切勿接 5V

            MOSI	GPIO13 (D7)	SPI 数据
            SCK	GPIO14 (D5)	SPI 时钟
            XCS (CS)	GPIO15 (D8)	片选，需下拉电阻
            XDCS (DCS)	GPIO0 (D3)	数据片选，启动需上拉
            DREQ	GPIO16 (D0)	数据请求中断
            XRST	3.3V	复位，可接 RC 复位电路
按键	上一台	GPIO2 (D4)	内部上拉，按下接 GND
下一台	GPIO3 (RX)	内部上拉，按下接 GND
音量+	GPIO10 (SD3)	内部上拉，按下接 GND
音量-	GPIO9 (SD2)	内部上拉，按下接 GND
电源	18650 电池	TP4056 输入	
TP4056 输出	降压模块输入	输出稳定 3.3V 接 ESP8266 的 3.3V 脚
电池供电要点：18650 电压范围约 3.0V–4.2V，不能直接接 ESP8266 的 3.3V 脚。建议使用 TP4056 模块负责充电与过放保护，后接 高效率降压模块（如 MP1584 或 Mini360）输出稳定 3.3V。ESP8266 在发射 Wi-Fi 时峰值电流可达 300mA 以上，降压模块需保证至少 500mA 输出能力。
